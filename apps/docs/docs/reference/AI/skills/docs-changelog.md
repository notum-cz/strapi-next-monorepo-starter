# docs-changelog

Generate a changelog from recent commits and audit documentation for gaps left by code changes. Produces a report with a changelog draft and a list of potential documentation issues.

## Use it when

- You want a summary of what changed in the last week or day.
- You suspect docs have drifted from code and want a gap analysis.
- You want a period work summary on `dev`. Versioned release notes on `main` are already generated by [semantic-release](../../workflow.md#release-notes) as GitHub Releases.

## What it does

**Changelog generation:**

1. Collects commits since the last run (or a specified date/SHA).
2. Parses Conventional Commit subjects and categorizes them (Added, Fixed, Changed, Dependencies, Infrastructure, etc.).
3. Skips GitHub merge commits, extracts the squash-merge `(#N)` PR number, and links each entry to its commit and PR.
4. Produces a formatted changelog entry ready for `apps/docs/docs/reference/changelog.md`.

**Docs audit (4 layers):**

1. **Code-to-Docs Map** — checks a maintained mapping of code paths to doc pages; flags when code changed but related docs didn't.
2. **Commit Scope Analysis** — flags `feat` commits whose scope has no matching doc changes.
3. **Environment Variable Detection** — finds new `process.env.*` references not documented in the env-vars pages.
4. **Structural Checks** — verifies that backticked file paths and internal links in modified doc pages still resolve.

## Flags

| Flag                     | Default                       | Purpose                          |
| ------------------------ | ----------------------------- | -------------------------------- |
| `--since=<sha\|date>`    | last-run marker or 7 days ago | Start of commit range            |
| `--period=daily\|weekly` | `weekly`                      | Heading format                   |
| `--changelog-only`       | off                           | Skip docs audit                  |
| `--audit-only`           | off                           | Skip changelog                   |
| `--dry-run`              | off                           | Print report only, write nothing |

## Output

The skill is **report-only** — it prints the changelog draft and audit findings but does not auto-commit or create PRs. It saves drafts to gitignored files under `.claude/skills/docs-changelog/` and suggests applying them via `/start-work`.

## Scheduling

After testing the skill manually, set up a recurring schedule:

```bash
/schedule create --cron "23 9 * * 1" --name "docs-changelog-weekly" \
  --prompt "Run /docs-changelog --period=weekly on dev."
```
