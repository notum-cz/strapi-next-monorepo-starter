Hands-on QA workshop covering the whole QA project — test types, tooling, and the QA docs.

## What you'll walk away with

- 🗺️ **A shared map** of every test type in this project and how they fit together
- 🎭 **Hands-on with every Playwright layer** — E2E, axe, SEO, visual, Lighthouse, CI
- 📋 **Comfortable with the new QA docs** — Gherkin test cases, Pass/Fail checklist, Test Plan export
- 🤖 **Two agent skills** that do a lot of this for you — `write-test-cases` and `write-tests`
- ✅ **A test case you wrote, automated, and ran** — locally and in CI
